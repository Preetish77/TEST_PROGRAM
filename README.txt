Campaign Export Analyzer — Setup for teammates
==============================================

REQUIREMENTS
- Windows PC
- Python 3 installed from https://www.python.org/downloads/
  (Check "Add Python to PATH" during install)

HOW TO RUN
1. Unzip the full folder (do not move START_APP.bat out on its own)
2. Double-click START_APP.bat
3. Browser opens at http://127.0.0.1:5000
4. Keep the black window open while using the app

REQUIRED FILES (must all be in the same folder)
- START_APP.bat
- app.py
- analyzer.py
- ko_parser.py
- requirements.txt
- templates\index.html

IF YOU SEE "requirements.txt not found"
You only received part of the project. Ask for the full ZIP again.

TO SHARE WITH A TEAMMATE (on your PC)
Double-click PACK_FOR_TEAMMATE.bat — sends Campaign_Export_Analyzer_Package.zip
